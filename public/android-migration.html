Passer à Vela 2.11

Vela utilise désormais une clé de signature Android durable. Le passage depuis la version 2.10.1 ou une version antérieure nécessite une réinstallation exceptionnelle.

  1. Dans l’application actuelle, lancez Profil → Synchroniser. Vérifiez sur le site que vos dernières notes, vos avis et vos listes sont présents. Conservez aussi un export JSON de secours lorsque disponible.
  2. Gardez l’ancienne application installée jusqu’à ce que votre sauvegarde et le téléchargement soient vérifiés. Une désinstallation efface les données locales de l’application.
  3. Téléchargez la nouvelle APK, désinstallez l’ancienne application, puis installez Vela 2.11.
  4. Reconnectez-vous avec le même compte pour restaurer les données effectivement synchronisées.

Les versions qui utilisent déjà la nouvelle signature pourront recevoir les prochaines mises à jour directement. Cette transition ne nécessite aucune nouvelle migration SQL.

Upgrading from Vela 2.10.1 or earlier

This release starts a persistent Android signing key. A one-time reinstall is required. Sync from the old app, verify your latest data on the website and keep a JSON backup when available. Download the new APK before uninstalling the old app. Uninstalling removes local app data. Install Vela 2.11 and sign in with the same account to restore data that was successfully synced. Later releases using this signing key can update in place.
